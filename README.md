# HWIDOHOLY-iOS-TestKi
HWIDOHOLY iOS TestKit

Projeto experimental para preparar um ambiente de compilação iOS usando GitHub Actions e macOS na nuvem.

Objetivo

* Preparar um ambiente de build para iOS.
* Gerar artefatos de teste.
* Documentar o processo de compilação e validação.

Segurança

Este projeto começa com uma interface de diagnóstico independente, sem modificar a memória de jogos nem implementar aimbot ou ESP.

Compilação

O workflow de compilação será configurado em .github/workflows/build.yml.
